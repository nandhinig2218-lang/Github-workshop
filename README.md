# Shopping List Management System

## About the Project
The Shopping List Management System is a menu-driven C++ program developed as a Data Structures case study. It allows users to manage shopping items easily through a simple console interface.

## Features
- Add an item to the shopping list.
- Remove an existing item.
- Search for an item.
- Display all shopping list items.
- Exit the program.

## Technologies Used
- Programming Language: C++
- Data Structure: Vector
- Header Files: iostream, vector, string, algorithm

## How It Works
The program displays a menu with five options. The user selects an operation by entering a number. Items are stored in a vector, and the user can add, remove, search, and display items.
